(Thresholds are proposals to be set before the first model run: consistent = spread <= 1.3 and CV <= 0.2; swings = spread >= 1.6 or CV > 0.3.)

CAUTIONS
  * A gauge is a point and a radar cell is 1 km across. For patchy convective storms the two can differ even when both are right.
  * Tipping-bucket gauges under-count in very heavy rain and in wind; no catch correction is applied here.
  * MRMS gauge-corrected products use many gauges. If these FCDMC gauges feed the product, agreement is partly built in.
  * Three gauges and four storms is a small sample. Treat the proposed reading as a prompt for the SRP discussion, not a result.
